# STAT 107 Study Hub

A responsive five-page, offline-friendly (after files are loaded) HTML/CSS/vanilla JavaScript study website.

## Getting started
Open `index.html` in a browser. Navigate using the top menu. No installation or server is needed.

## Customize
- Edit `data.js` to update the course dates, concepts, formulas, flashcards, quiz questions, weekly checklist and default resources.
- Edit `style.css` to change colors and layout.
- Edit the individual `.html` pages for headings and descriptions.
- Add resources using the form on the Resources page.

Checklist completion, flashcard status, mistake log, and user-added resource links are saved in `localStorage` for that browser. Clearing browser data resets them. There is no cloud synchronization or login.

Course topics and weekly dates are a suggested plan, not a verified copy of the Fall 2026 course schedule. Confirm exam scope, assignment due dates and policies in UIUC Canvas.
